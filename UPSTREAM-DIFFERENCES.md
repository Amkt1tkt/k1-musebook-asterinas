This index describes the changes carried by the K1 MUSE Book port relative to
that upstream revision. Each entry states the implementation change and why it
is needed. Paths link to the current source; removed upstream files link to the
baseline revision. Generated ABI tables, firmware, and third-party license text

Update this index when changing a downstream implementation or advancing the
upstream baseline. Describe the current contract rather than the development
history; build and hardware validation records are maintained separately.
